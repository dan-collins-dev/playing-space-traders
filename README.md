# st-node-cli

The purpose of this project is to learn how to build a CLI with NodeJS that communicates with the [SpaceTraders.io](https://spacetraders.io/) API.

## Running Locally

#### Required Tools

- [Node.js](https://nodejs.org/)  v24.18
- [VSCode](https://code.visualstudio.com/)
- [REST Client VSCode Extension ](https://marketplace.visualstudio.com/items?itemName=humao.rest-client)
	- For running requests from `.http` files


```bash
git clone https://github.com/dan-collins-dev/st-node-cli.git
cd st-node-cli
```
